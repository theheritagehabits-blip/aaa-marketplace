# AAA Marketplace

AAA Marketplace is a hyperlocal services Progressive Web App (PWA) built by **Manglam World**. It enables users to discover and access local services with a seamless, installable web experience that works offline.

---

## ⚠️ Important: This is a Build Artifact

The default branch (`gh-pages`) is a **build artifact**. It is overwritten on every deploy.

> **Contributors: Do NOT make source edits on this branch.**
> Any change made here will be **lost** on the next deploy.

To contribute, edit the source elsewhere and submit a pull request. The deploy process will regenerate this branch automatically.

---

## Project Structure

| Path | Description |
|------|-------------|
| `assets/` | Static assets (CSS, images, fonts) |
| `banners/` | Banner images used throughout the app |
| `services/` | Service listings and service detail pages |
| `icons3d/` | 3D icons for the PWA interface |
| `sw.js` | Service worker for offline support and caching |
| `manifest.webmanifest` | PWA web app manifest (name, icons, theme, installability) |

---

## PWA Features

- **Installable**: Add to home screen on mobile and desktop
- **Offline Support**: Works without internet via service worker caching
- **Responsive**: Adapts to any screen size
